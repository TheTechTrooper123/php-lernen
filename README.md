# PHP lernen

Dieses Repository enthält meine PHP-Übungsbeispiele und Notizen, die ich beim
Lernen mit dem PHP-Tutorial von W3Schools erstellt habe.

Der Code basiert auf bzw. orientiert sich an:
https://www.w3schools.com/php/default.asp

## Inhalt

Die Beispiele bauen aufeinander auf – von den Grundlagen bis zu komplexeren
Themen:

- Variablen
- Datentypen
- Ausgabe mit `echo` und `print`
- Zeichenketten
- Arrays (Felder)
- Schleifen
- Funktionen
- Superglobale Variablen
- Formulare
- Fortgeschrittene Themen (Dateien, Cookies, Sessions, Filter, JSON, Ausnahmen …)
- Objektorientierte Programmierung
- MySQL
- XML
- AJAX
- Reguläre Ausdrücke

Zu vielen Beispielen liegen zusätzlich kurze Notizen (`*_notiz.txt`) bei, in
denen das jeweilige Thema zusammengefasst ist.

## Hinweis

Alle Beispiele dienen dem Lernen und Üben und wurden anhand des
W3Schools-Tutorials erstellt und nachvollzogen.
